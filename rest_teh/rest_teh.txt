## 🔧 3. Ключевые конфигурационные файлы и их содержимое

### 3.1 Бэкенд: `/var/www/rest-tech/backend/main.py`
```python
from fastapi import FastAPI
from fastapi.staticfiles import StaticFiles
from pathlib import Path

app = FastAPI(title="РЕСТ-ТЕХ")

# Путь к собранному фронтенду
frontend_dist = Path(__file__).parent.parent / "frontend" / "dist"

# === API-ЭНДПОИНТЫ (объявляются ДО монтирования статики) ===
@app.get("/api/health")
async def health_check():
    return {
        "status": "ok",
        "service": "rest-tech-backend",
        "python": "3.14",
        "node": "24",
        "frontend_built": frontend_dist.exists()
    }

# === МОНТИРОВАНИЕ СТАТИКИ ФРОНТЕНДА ===
if frontend_dist.exists():
    # Важно: mount("/", ...) должен быть ПОСЛЕ всех @app.get декораторов
    app.mount("/", StaticFiles(directory=str(frontend_dist), html=True), name="frontend")
```

### 3.2 Веб-сервер: `/etc/nginx/sites-available/rest-tech.conf`
```nginx
server {
    listen 80;
    # Все доменные имена, которые должен обслуживать этот сервер
    server_name рест-тех.рф www.рест-тех.рф xn----itbb5bggbz.xn--p1ai www.xn----itbb5bggbz.xn--p1ai 45.151.30.217;

    # Перенаправление всех HTTP-запросов на HTTPS (добавлено Certbot)
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name рест-тех.рф www.рест-тех.рф xn----itbb5bggbz.xn--p1ai www.xn----itbb5bggbz.xn--p1ai;

    # SSL-сертификаты, выданные Let's Encrypt (пути управляются Certbot)
    ssl_certificate /etc/letsencrypt/live/xn----itbb5bggbz.xn--p1ai/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/xn----itbb5bggbz.xn--p1ai/privkey.pem;
    include /etc/letsencrypt/options-ssl-nginx.conf;
    ssl_dhparam /etc/letsencrypt/ssl-dhparams.pem;

    # Корневая директория статических файлов фронтенда
    root /var/www/rest-tech/frontend/dist;
    index index.html;

    # Основное правило для SPA (Single Page Application)
    location / {
        try_files $uri $uri/ /index.html;
    }

    # Проксирование API-запросов на бэкенд FastAPI
    location /api {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # Кэширование статических ресурсов на стороне клиента
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

## 🔄 5. Жизненный цикл проекта: основные команды управления

### 5.1 Разработка и обновление кода
*   **Обновить фронтенд (после изменений в `frontend/src/`)**:
    ```bash
    cd /var/www/rest-tech/frontend
    npm run build
    # Бэкенд автоматически раздаст новые файлы из `frontend/dist/`
    ```
*   **Обновить зависимости бэкенда**:
    ```bash
    cd /var/www/rest-tech
    source .venv/bin/activate
    uv pip install <пакет>
    ```
*   **Обновить зависимости фронтенда**:
    ```bash
    cd /var/www/rest-tech/frontend
    npm install <пакет>
    ```

### 5.2 Мониторинг и логи
*   **Просмотр логов бэкенда (FastAPI)**:
    ```bash
    sudo journalctl -u rest-tech.service -f
    ```
*   **Просмотр логов веб-сервера (Nginx)**:
    ```bash
    # Ошибки
    sudo tail -f /var/log/nginx/error.log
    # Весь доступный трафик
    sudo tail -f /var/log/nginx/access.log
    ```
*   **Проверка статуса всех сервисов**:
    ```bash
    sudo systemctl status nginx rest-tech.service
    ```

### 5.3 Безопасность и обслуживание
*   **Обновление SSL-сертификата (выполняется автоматически, вручную проверить)**:
    ```bash
    sudo certbot renew --dry-run
    ```
*   **Обновление системных пакетов на VPS**:
    ```bash
    sudo apt update && sudo apt upgrade -y
    ```

## 🚀 6. Архитектура проекта в продакшене
```
[Клиентский браузер]
        ↓ (HTTPS запрос на 443 порт)
[Cloud.ru VPS: Nginx]
        ├───→ (Запросы к /api/*) → [FastAPI на 127.0.0.1:8000]
        └───→ (Все остальные запросы) → [Статика React из /frontend/dist]
```

Ваш сайт представляет собой современное **одностраничное приложение (SPA)** на React, которое обслуживается быстрым **веб-сервером Nginx** с автоматическим **HTTPS**, а бизнес-логика может быть расширена через **API на FastAPI**.

Проект полностью готов к развитию: вы можете добавлять новые компоненты во фронтенде, создавать API-эндпоинты в бэкенде и наполнять разделы контентом.
