## 📁 1. Структура проекта

```

├── App.tsx                            # Главный компонент приложения с роутингом
```

## 🏗 3. Архитектура приложения

### 3.1 Общая структура

```
[Пользователь]
     ↓
[React Router] — управляет навигацией
     ↓
[App.tsx] — корневой компонент
     ├─→ [Header] — навигация (всегда видна)
     ├─→ [Routes] — динамический контент
     │    ├─→ / — [Home] — главная страница
     │    ├─→ /projects — [Projects] — проектирование
     │    ├─→ /supply — [Supply] — снабжение
     │    └─→ /training — [Training] — обучение
     └─→ [Footer] — контакты и ссылки (всегда виден)
```

### 3.2 Принципы архитектуры

- **SPA (Single Page Application)** — сайт работает без перезагрузки страницы
- **Component-Based** — модульная структура с переиспользуемыми компонентами
- **Responsive Design** — адаптивная вёрстка для всех устройств (мобильные, планшеты, десктопы)
- **Performance-First** — оптимизация загрузки и рендеринга

