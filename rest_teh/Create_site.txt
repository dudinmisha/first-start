Отлично! У вас есть готовый, современный сайт, созданный с помощью AI агента в Figma, и полная техническая документация. Теперь нужно перенести этот дизайн из Figma в ваш реальный проект на VPS, следуя лучшим практикам UX.

Вот подробный гайд по работе с Figma и интеграции дизайна, состоящий из 6 ключевых этапов.

## 🎯 Этап 1: Анализ и подготовка дизайн-макета

Перед вёрсткой тщательно изучите макет в Figma, чтобы избежать ошибок при переносе.

1.  **Проверка дизайн-системы в Figma:**
    *   Откройте панель **«Assets»**. Убедитесь, что все цвета, текстовые стили (H1, H2, Body) и компоненты (Кнопки, Карточки) оформлены как **«Styles»** и **«Components»**. Это основа для единообразия.
    *   **Экспортируйте стили:** В **«Dev Mode»** (`Shift+I`) скопируйте значения всех цветов (например, `brand.500: #0066cc`) и шрифтов.
    *   **Изучите адаптивность:** Посмотрите, как дизайнер спроектировал поведение макета на разных экранах. Обратите внимание на изменения: размера шрифта, сетки (например, с 3 колонок на 1), скрытия элементов.

2.  **Создание чек-листа компонентов:**
    Составьте таблицу, что нужно создать в коде. Пример для главной страницы:
    | Компонент (в коде) | Тип | Кол-во | Особенность из Figma | Состояния |
    | :--- | :--- | :--- | :--- | :--- |
    | `GradientButton` | UI | 2 вида | Градиент, тень при hover | Default, Hover, Disabled |
    | `ServiceCard` | Секция/Блок | 6 шт | Эффект поднятия при наведении | Default, Hover |
    | `TrustBadge` | UI | 3 шт | Иконка + текст | — |
    | `HeroSection` | Секция/Блок | 1 | Фон-градиент, сложная сетка | — |

**Пример 2: Создание интеллектуального фильтра для `Supply.tsx` из макета**

Макет Figma показывает интерактивные фильтры. Реализуем их с сохранением логики UI/UX.

```tsx
// src/components/Supply/EquipmentFilter.tsx
import { useState } from 'react';
import { HStack, Button, Wrap, WrapItem, useBreakpointValue } from '@chakra-ui/react';

const categories = [
  { id: 'all', label: 'Всё оборудование', icon: 'Grid' },
  { id: 'cooking', label: 'Тепловое', icon: 'Flame' },
  { id: 'cold', label: 'Холодильное', icon: 'Snowflake' },
  { id: 'prep', label: 'Подготовка', icon: 'ChefHat' },
  // ... другие категории из макета
];

export const EquipmentFilter = ({ onFilterChange }) => {
  const [activeFilter, setActiveFilter] = useState('all');
  // Адаптивное поведение: на мобильном фильтры переносятся, на десктопе в строку
  const filterDirection = useBreakpointValue({ base: 'wrap', md: 'row' });

  const handleFilterClick = (categoryId) => {
    setActiveFilter(categoryId);
    onFilterChange(categoryId); // Передаём выбор родителю
  };

  return (
    <Wrap spacing={3} justify="center" py={6}>
      {categories.map((category) => (
        <WrapItem key={category.id}>
          <Button
            size="lg"
            variant={activeFilter === category.id ? 'solid' : 'outline'}
            colorScheme={activeFilter === category.id ? 'blue' : 'gray'}
            // Динамические классы Tailwind для точного соответствия Figma
            className={`
              rounded-full px-6 py-3 font-medium transition-all
              ${activeFilter === category.id 
                ? 'bg-gradient-to-r from-blue-600 to-purple-600 text-white shadow-lg' 
                : 'border-2 border-gray-200 hover:border-blue-300'
              }
            `}
            leftIcon={<category.icon size={18} />}
            onClick={() => handleFilterClick(category.id)}
          >
            {category.label}
          </Button>
        </WrapItem>
      ))}
    </Wrap>
  );
};
```

## 🚀 Этап 4: Реализация улучшений UX из макета

**1. Внедрение плавной навигации и визуального состояния:**

```tsx
// Улучшенный Header.tsx - добавление индикатора прокрутки и плавного скролла
import { useEffect, useState } from 'react';
import { Link, useLocation } from 'react-router-dom';

export const Header = () => {
  const [scrolled, setScrolled] = useState(false);
  const location = useLocation();

  useEffect(() => {
    const handleScroll = () => {
      setScrolled(window.scrollY > 20);
    };
    window.addEventListener('scroll', handleScroll);
    return () => window.removeEventListener('scroll', handleScroll);
  }, []);

  // Плавный скролл к якорям на той же странице
  const handleSmoothScroll = (hash) => {
    if (location.pathname === '/') {
      const element = document.querySelector(hash);
      if (element) {
        element.scrollIntoView({ behavior: 'smooth', block: 'start' });
      }
    }
  };

  return (
    <header 
      className={`
        sticky top-0 z-50 transition-all duration-300
        ${scrolled 
          ? 'bg-white/90 backdrop-blur-lg shadow-lg py-3' 
          : 'bg-transparent py-5'
        }
      `}
    >
      {/* Навигация с активным состоянием, как в макете */}

        <Link

            relative font-medium px-4 py-2 rounded-lg transition-colors
```

**2. Динамическая загрузка изображений через Unsplash API:**
```typescript
// Создайте сервисный файл src/services/imageService.ts
const UNSPLASH_ACCESS_KEY = 'ваш_ключ'; // Вынесите в .env

export const loadOptimizedImages = async (query: string, count: number = 3) => {
  try {
    const response = await fetch(
      `https://api.unsplash.com/search/photos?query=${encodeURIComponent(query)}&per_page=${count}&client_id=${UNSPLASH_ACCESS_KEY}`
    );
    const data = await response.json();
    return data.results.map(img => ({
      url: `${img.urls.raw}&auto=format&fit=crop&w=800&q=80`, // Оптимизация на лету
      alt: img.alt_description || query,
      author: img.user.name,
      blurHash: img.blur_hash // Для эффекта placeholder
    }));
  } catch (error) {
    console.error('Ошибка загрузки изображений:', error);
    return [];
  }
};

// Использование в компоненте Projects.tsx
import { useEffect, useState } from 'react';
import { loadOptimizedImages } from '../services/imageService';

const ProjectsGallery = () => {
  const [projectImages, setProjectImages] = useState([]);

  useEffect(() => {
    const loadImages = async () => {
      const images = await loadOptimizedImages('restaurant interior design modern', 3);
      setProjectImages(images);
    };
    loadImages();
  }, []);

  return (
    <div className="grid md:grid-cols-3 gap-6">
      {projectImages.map((img, idx) => (
        <div key={idx} className="relative rounded-2xl overflow-hidden shadow-lg">
          <img 
            src={img.url} 
            alt={img.alt}
            loading="lazy" // Ленивая загрузка для производительности
            className="w-full h-64 object-cover transition-transform duration-700 hover:scale-110"
          />
          <div className="absolute bottom-0 left-0 right-0 bg-gradient-to-t from-black/70 to-transparent p-4">
            <p className="text-white text-sm">Автор: {img.author}</p>
          </div>
        </div>
      ))}
    </div>
  );
};
```
